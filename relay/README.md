# Ableton Link companion relay

GitHub Pages serves the browser instrument; native Ableton Link runs here on your computer. The relay joins Link peers on your LAN and supplies tempo/beat snapshots over WebSocket. It binds to `127.0.0.1` by default and only accepts the configured web origins. It follows Link tempo/phase; it does not forward MIDI/audio or control remote play/stop.

## Install

Use Node 22.18+ and the native build prerequisites for your OS: Python and C++ build tools (Visual Studio C++ Build Tools on Windows, Xcode Command Line Tools on macOS, or make/g++ on Linux).

```sh
cd relay
npm ci
npm start
```

`@ktamas77/abletonlink` is optional so a native compilation failure does not prevent web-app installation. If it failed, install the build prerequisites and run `npm rebuild @ktamas77/abletonlink`. Startup reports the error if the binding is unavailable; it never silently substitutes a fake Link clock.

## HTTPS / GitHub Pages

The hosted app defaults to `wss://localhost:20808`. Supply a localhost certificate and key trusted by your OS/browser (for example, generated by an installed local certificate tool). Do not commit private keys.

macOS/Linux shell:

```sh
TLS_CERT=/absolute/path/localhost.pem TLS_KEY=/absolute/path/localhost-key.pem npm start
```

PowerShell:

```powershell
$env:TLS_CERT = 'C:\certs\localhost.pem'
$env:TLS_KEY = 'C:\certs\localhost-key.pem'
npm start
```

Open the generator, choose **Ableton Link relay** as synchronization, connect `wss://localhost:20808`, then press Play. Enable Link in your DAW on the same network. The UI reports peer count and measured tempo. Depending on browser version, permission to connect to a local network endpoint may be required. A self-signed certificate that is not trusted by your browser will not work.

For local HTTP development at `http://localhost:5173`, `ws://localhost:20808` can be used without TLS. Mixed-content rules can block plain `ws://` from GitHub Pages, so it is not the hosted default.

Environment variables:

- `PORT`: default 20808.
- `TLS_CERT` / `TLS_KEY`: paths to the PEM certificate/key.
- `ALLOWED_ORIGINS`: comma-separated exact origins. Default `https://djshellshoxxx.github.io,http://localhost:5173`. Add your own origin if using a different host.

## Protocol

Client sends `{"type":"sync","sent":<client epoch milliseconds>}` every 100 ms. Server replies `{"type":"sync","sent":<echo>,"beat":<Link beat>,"bpm":<tempo>,"peers":<count>}`. Client validates finite bounded values and estimates snapshot time using half the round-trip duration. Connections without valid snapshots time out. The server rejects payloads over 1 KB and unapproved origins; timing requests are rate limited.

```sh
npm test
```

The protocol test injects a known clock and checks timing snapshots plus origin rejection. This is separate from testing with a real Link session.
